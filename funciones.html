Funciones que hacen la vivienda más inteligente.

El kit de referencia de Keyestudio simula una casa inteligente con diferentes elementos controlables mediante programación y dispositivos de entrada/salida.

💡

Iluminación inteligente

Control y automatización de luces LED. La iluminación puede responder a condiciones o acciones programadas.

🪟

Cortinas automáticas

Uso de motores o servomotores para representar la apertura y cierre automático de cortinas.

🌡️

Temperatura y ambiente

Sensores permiten obtener información del entorno para apoyar decisiones automáticas.

🚪

Acceso electrónico

Una cerradura electrónica puede representar un sistema de acceso controlado.

📱

Control remoto

El sistema de referencia contempla control mediante dispositivos como celular o control remoto.

🚨

Seguridad y alertas

Los sensores pueden detectar situaciones y activar respuestas como luces, sonidos o avisos.
