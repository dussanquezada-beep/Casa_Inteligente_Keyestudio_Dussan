04 · TECNOLOGÍAS

La tecnología detrás del proyecto.

La propuesta se basa en conceptos de Arduino, sensores, actuadores y programación para representar una vivienda automatizada.

🧠

Arduino / PLUS Board

La placa funciona como controlador: recibe información y ejecuta instrucciones programadas.

👁️

Sensores

Permiten detectar condiciones como luz, movimiento, temperatura u otras variables del entorno.

⚙️

Actuadores

LED, motores, servomotores y otros componentes realizan las acciones indicadas por el controlador.

💻

Programación

El código define reglas: si ocurre una condición, el sistema ejecuta una respuesta.

🌐

Control

El concepto puede incorporar control remoto o mediante dispositivos móviles, según la implementación.

🔌

Electrónica

La conexión entre placa, sensores y actuadores permite construir un prototipo funcional.
