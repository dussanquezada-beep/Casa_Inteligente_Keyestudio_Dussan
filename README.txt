CASA INTELIGENTE - PROYECTO TÉCNICO PROFESIONAL

Archivos:
- index.html
- objetivo.html
- funciones.html
- beneficios.html
- tecnologias.html
- conclusion.html
- style.css
- script.js

Uso:
1. Abre la carpeta en Visual Studio Code.
2. Abre index.html con Live Server (recomendado) o directamente en el navegador.
3. Las imágenes del proyecto apuntan a imágenes alojadas por Keyestudio/CDN de su página oficial.
4. Si quieres trabajar sin Internet, descarga las imágenes de la página oficial y colócalas en una carpeta "img", reemplazando las URLs de las etiquetas <img>.
